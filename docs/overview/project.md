# プロジェクト概要

## 目的

Money ForwardからダウンロードしたCSVファイルを取り込み、長期的に取引データを蓄積する。
蓄積したデータをもとに、Money Forward標準機能とは異なる独自の視点で分析し、HTMLレポートとして出力する。

## 想定ユーザー

- 個人利用者
- Money ForwardのCSVを定期的にダウンロードできる人
- 支出、収入、資産推移、カテゴリ別傾向などを自分の観点で確認したい人

## 現在の状態

- 要件定義のたたき台は作成済み。
- CSV原本の保存先は `data/csv/`。
- サンプルCSVは `data/csv/収入・支出詳細_2026.csv`。
- サンプルCSVは2026年分のみで、実際には複数年分が蓄積される前提。
- アプリケーションコードはまだ存在しない。

## 重要な前提

- Money Forwardへの自動ログインやスクレイピングは初期スコープ外。
- CSVはユーザーが手動でダウンロードし、`data/csv/` に配置する。
- CSV原本は取り込み後も削除しない。
- DBにはすべての行を保存する。
- 標準の収支分析では `計算対象=1` かつ `振替=0` の明細を対象にする。
- 振替行や計算対象外の行は、標準レポートから除外するが、確認用に保持する。
