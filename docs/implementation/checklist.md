# 実装チェックリスト

## マイルストーン1: 取り込み基盤

- Pythonパッケージ構成を作る。
- デフォルトパスを定義する。
  - CSVディレクトリ: `data/csv/`
  - DBパス: `data/db/finance_analysis.sqlite3`
  - レポートディレクトリ: `reports/`
- SQLiteスキーマを作成する。
  - `import_files`
  - `transactions`
  - `category_rules`
- `utf-8-sig` でCSVを読む。
- 必須列を検証する。
- 日付をISO形式 `YYYY-MM-DD` に正規化する。
- 金額を整数の円金額に正規化する。
- 元行をJSONとして保存する。
- `ID` で重複排除し、必要に応じて行ハッシュへフォールバックする。
- 匿名化したfixture CSVを使ってテストを追加する。

## マイルストーン2: 基本分析

- 月別の収入、支出、収支を集計する。
- Money Forwardの大項目カテゴリ別に支出を集計する。
- 高額支出明細を一覧化する。
- 計算対象外または振替行の件数と金額を集計する。
- 未分類行を抽出する。

## マイルストーン3: HTMLレポート

- 単体で開けるHTMLファイルを生成する。
- サマリー指標を含める。
- 月別テーブルを含める。
- カテゴリ別テーブルを含める。
- 高額支出テーブルを含める。
- インラインSVG、CSSバー、またはローカルで完結する静的JSにより、基本的なグラフを含める。

## 受け入れ条件

- インポートを再実行しても取引が重複しない。
- 複数CSVファイルを取り込める。
- 標準レポートでは `振替=1` を除外する。
- 生成されたレポートをブラウザで直接開ける。
- コマンド実行にネットワークアクセスが不要。
- 個人データファイルがGit管理対象外のままになっている。
