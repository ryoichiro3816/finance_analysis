# 0001: ローカルCLI、SQLite、静的HTML

## ステータス

提案中

## 背景

このプロジェクトでは、Money Forwardからエクスポートした個人の家計データを扱う。
ユーザーは、データを蓄積するDBと、そのデータから生成するHTMLレポートを求めている。

## 決定

初期実装は、PythonによるローカルCLIアプリケーション、SQLite、静的HTML出力で開始する。

## 理由

- 個人データをローカルに閉じて扱える。
- 不要なサーバーやクラウド構成を避けられる。
- 複数年にまたがる繰り返し取り込みに対応しやすい。
- 生成レポートを開きやすく、保存しやすい。
- 最初の実装を小さく保ち、早く検証できる。

## 影響

- 最初のユーザー体験はCLIになる。
- 将来的にWeb UIを作る場合も、取り込み、DB、分析レイヤーは再利用する。
- 生成レポートはアプリケーションサーバーなしで閲覧できるようにする。
