# Money Forward CSV仕様

## 対象CSV

初期対象はMoney Forwardの「収入・支出詳細」CSV。

確認済みファイル:

- `data/csv/収入・支出詳細_2026.csv`

## 確認済みCSV概要

- データ行数: 681件
- 対象期間: 2026/01/01から2026/07/01
- 文字コード: UTF-8 BOM付きCSV
- 日付形式: `YYYY/MM/DD`
- ID列の重複: なし
- メモ列: 全件空欄
- `計算対象=1`: 602件
- `計算対象=0`: 79件
- `振替=0`: 602件
- `振替=1`: 79件

## 確認済み列

| 列名 | 意味 | 初期方針 |
| --- | --- | --- |
| `計算対象` | Money Forward上で計算対象かどうか | 真偽値相当の整数として保存 |
| `日付` | 取引日 | `YYYY/MM/DD` として読み、ISO日付へ変換 |
| `内容` | 取引内容 | 元の文字列を保存 |
| `金額（円）` | 符号付きの円金額 | 整数として保存 |
| `保有金融機関` | 口座、カード、金融機関 | 元の文字列を保存 |
| `大項目` | 大項目カテゴリ | 元の文字列を保存 |
| `中項目` | 中項目カテゴリ | 元の文字列を保存 |
| `メモ` | メモ | 元の文字列を保存。空欄の場合あり |
| `振替` | 振替フラグ | 真偽値相当の整数として保存 |
| `ID` | Money Forwardの取引ID | 外部一意キーとして利用 |

## パースルール

- `utf-8-sig` で読み込む。
- 金額は符号付き整数の円金額として扱う。
- プラス金額は収入。
- マイナス金額は支出。
- 標準の分析対象行は `計算対象=1` かつ `振替=0`。
- 標準分析対象外の行も、フラグ付きの通常取引としてDBへ保存する。

## 重複排除

優先する重複排除キー:

- `ID`

フォールバックの重複排除キー:

- 正規化した行内容から作る安定した行ハッシュ。

同じCSVを繰り返し取り込んでも、インポート結果が重複しないこと。
